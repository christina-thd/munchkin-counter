munchkin-counter/                  Home Assistant add-on containing the app
                                   (in the repository it sits next to repository.yaml and the repo README)
├── config.yaml                    add-on definition: version, ingress, host network, host_ip option, share:ro
├── Dockerfile                     Home Assistant base image + Node.js, copies src/ and public/
├── run.sh                         bashio: add-on options → env vars (HOST_IP, LOGO_FILE), https certificate, starts the server
├── README.md                      add-on store page: features, install, options
├── DOCS.md                        add-on Documentation tab: usage, rules, sound, custom logo
├── CHANGELOG.md                   release notes (shown in Home Assistant)
├── icon.png, logo.png             add-on store icon (128×128) and banner (250×100)
├── art/                           store-logo.svg, render.sh (PNG images), wake-video.sh (keep-awake video)
├── package.json                   version, scripts (start, dev, test), one dependency (qrcode)
├── src/                           server (Node, no framework)
│   ├── server.js                  entry point: http (+ https on 3443), graceful shutdown
│   ├── config.js                  environment variables (PORT, HOST, HOST_IP, STATE_FILE, LOGO_FILE)
│   ├── app.js                     HTTP routes: pages, static files, /logo, /qr.svg, /munchkin-counter.crt, API
│   ├── game/state.js              state shape, migrations, view for clients
│   ├── game/actions.js            every game action, validated
│   ├── store.js                   safe JSON saving (atomic, debounced)
│   ├── sse.js                     live updates to all screens
│   └── network.js, static.js      LAN address detection, safe static file serving
├── public/                        browser (plain ES modules, no build step)
│   ├── index.html                 start page: continue, new game, past games
│   ├── table.html, phone.html     dashboard, phone controls (markup only)
│   ├── css/   base.css, lobby.css, table.css, phone.css
│   ├── manifest.webmanifest       "Add to Home Screen" opens the app full screen
│   ├── img/   logo.svg            built-in logo (a custom one can replace it via LOGO_FILE), icon-*.png
│   ├── media/ wake.mp4, wake.webm tiny silent video that keeps the screen on over plain http
│   └── js/
│       ├── shared/  rules.js (used by server too), api, dialog, dom, format, games, screen, storage,
│       │            device-check.js (phones → /join; tablets and TVs keep the dashboard)
│       ├── lobby/   main.js       start page
│       ├── table/   main, board, sizing, dialogs, sounds,
│       │            announcer (situations, pure) + lines (texts) + ticker (UI)
│       └── phone/   main.js       phone controls
├── test/                          automated tests (Node's built-in runner, no extra deps):
│                                  actions, state, announcer, store, http, addon packaging, device check
└── docs/
    ├── DEVELOPMENT.md             dev setup, architecture, releasing, local Docker test
    └── _project_architecture.txt  this overview

Not in the repository: node_modules/ (npm install), data/ (local saved games)
